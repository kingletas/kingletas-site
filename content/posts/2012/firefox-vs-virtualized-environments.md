Firefox rocks no doubt about it... but using more memory than virtualbox just to run magento is not cool at all!

This is why I really dislike using FireFox and love using [SwiftFox](http://getswiftfox.com/). How come Firefox is taking 2GB of ram, that is as much as my virtualized Ubuntu Desktop and more than my virtualized ubuntu server. In other words with that much memory I could be running a few more computers.
